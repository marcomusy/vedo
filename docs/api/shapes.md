# vedo.shapes

<img src="https://vedo.embl.es/images/basic/extrude.png" alt="shapes">

Bundled 3D fonts use pickle-free NumPy archives. Official downloaded fonts are
checked against packaged SHA-256 hashes before loading. Custom legacy font
archives require the trusted-file opt-in described in
[NumPy files and trusted legacy data](file_io.md#numpy-files-and-trusted-legacy-data).
